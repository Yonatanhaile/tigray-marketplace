# Vercel Manual Deployment Guide

## Quick Deploy Steps:

1. **Go to Vercel Dashboard**: https://vercel.com/dashboard

2. **Find Your Project** (Tigray Market frontend)

3. **Click "Redeploy"** button

4. **Verify Settings**:
   - Framework: Vite
   - Build Command: `npm run build`
   - Output Directory: `dist`
   - Root Directory: `client` (if frontend is in client folder)

## If GitHub Auto-Deploy Isn't Working:

### Option A: Reconnect GitHub
1. Settings → Git
2. Disconnect repository
3. Reconnect and select your repo
4. Set production branch to `main`

### Option B: Deploy from CLI
```bash
# Install Vercel CLI
npm install -g vercel

# Navigate to your client folder
cd "C:\Users\user\Desktop\Tigray Market new\client"

# Deploy
vercel --prod
```

## Environment Variables to Set:
- `VITE_API_URL` = Your backend API URL (e.g., https://your-backend.render.com)

## Common Build Errors:

### Error: "Module not found"
- Make sure all dependencies are in package.json
- Check if imports match exact file names (case-sensitive)

### Error: "Build failed"
- Check build logs in Vercel dashboard
- Verify Node version compatibility
- Make sure all environment variables are set
